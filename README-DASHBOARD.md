# Project 25 — Streamlit Dashboard + Excel Report

This add-on reads the existing `output/customer_report.csv` generated by the original `main.py`.

## Original code preserved
- Do not replace or edit `main.py`.
- Copy `streamlit_app.py` beside `main.py` in the project root.
- Keep the CSV at `output/customer_report.csv`.

## Install
Activate the project's virtual environment, then run:

```bat
python -m pip install -r requirements-dashboard.txt
```

## Run
```bat
python -m streamlit run streamlit_app.py
```

## Features
- KPI cards for frames analysed, average detected people per frame, highest and lowest counts
- Line chart and count-distribution bar chart
- Frame-range filter and data table
- Download filtered CSV
- Download Excel workbook with a Summary sheet and Frame Records sheet

## Note
The original script counts detections in each frame; it does not count unique customers. Its `Time` column is the computer's processing time, not the video's original timestamp.
