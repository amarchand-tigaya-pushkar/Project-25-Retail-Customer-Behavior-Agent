# Project 25 — Retail Store Customer Behavior Analysis Agent

A computer-vision project that processes retail-store video, detects people with YOLO, displays frame-level detections using OpenCV, and exports frame-wise customer counts to CSV. A separate Streamlit dashboard visualizes the generated report and allows CSV/Excel downloads.

> **Code preservation:** The original `main.py` is preserved. The dashboard lives in `streamlit_app.py` and does not replace the original detection script.

## Features

- Person detection with YOLOv8 (`yolov8n.pt`)
- Video processing with OpenCV
- Frame-level person count overlay
- CSV report saved to `output/customer_report.csv`
- Streamlit KPI cards and charts
- Frame-range filter and report table
- Filtered CSV download
- Excel workbook download with `Summary` and `Frame Records` sheets

## Tech stack

Python, OpenCV, Ultralytics YOLO, Pandas, NumPy, Streamlit, OpenPyXL.

## Setup on Windows

Open CMD in the project folder:

```bat
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Place a video that you are permitted to use at:

```text
videos\store_video.mp4
```

Run the original video analysis:

```bat
python main.py
```

The YOLO model may be downloaded automatically on first run, so internet access may be required.

## Launch the Streamlit dashboard

After `output/customer_report.csv` has been generated:

```bat
python -m streamlit run streamlit_app.py
```

The dashboard normally opens in your browser. It reads `output/customer_report.csv` by default. You can also upload a compatible CSV from the sidebar.

For the test CSV used during development:

These figures describe that test report only; results will differ for other videos.

## Important interpretation notes

- `Customer Count` means the number of person detections in an individual frame. It is **not** the number of unique customers.
- The current original script records the computer's processing time in the `Time` column, not the video's original timestamp.
- Customer tracking IDs, unique visitor counting, entry/exit counting, and dwell-time analysis are not implemented in the original script.
